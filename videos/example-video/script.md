# Example Video: How This Repo Runs My Channel

> Sample script. Scripts are written for reading aloud, so expect short sentences.

## Intro (00:00)

This channel has a public repo. The scripts are in it, the descriptions are in it,
and if I get something wrong, you can fix it.

## How a video moves through the repo (00:20)

Every video is a folder. The `status` field says how far along it is: idea, draft,
scripted, recorded, published.

## Fixing mistakes (01:30)

If something in a video is wrong, I can't change the video. I can change the
write-up, so fixes go there.

## Wrap up (02:30)

Link in the description. Pull requests welcome.
