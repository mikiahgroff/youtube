This is the sample write-up. It renders on the site below the video, so a viewer who
would rather read gets the same information.

## What lives where

Each video has its own folder in `videos/`:

| File | Purpose |
| --- | --- |
| `meta.yaml` | Title, status, tags, corrections and credits |
| `script.md` | What gets said on camera |
| `description.md` | The hand-written part of the YouTube description |
| `chapters.yaml` | Chapter markers |
| `writeup.md` | This page |

## Corrections

Videos can't be edited after publishing, so errata go in `corrections` in `meta.yaml`.
They appear in the YouTube description and on this page.
